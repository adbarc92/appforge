## Decisions We've Made

### **Strategic Decisions**

1. **Target User**: You (and people like you)—technical, experienced, willing to write detailed specs
2. **Success Metric**: Ship your backlog of 12 apps faster than manual development
3. **Autonomy Definition**: 10 minutes of human oversight per phase, not zero-touch
4. **Foundation Strategy**: Agnostic where possible; accept some LangGraph lock-in as trade-off
5. **Testing Strategy**: Use YOUR real apps (not Todo MVC) starting Phase 6
6. **Cost Budget**: ~$500 for Phases 0-14 ($150 R&D, $250 building apps, $100 buffer)

### **Tactical Decisions**

1. **Orchestrator**: Start with lightweight LLM-based routing, compile to rules-based FSM once patterns emerge
2. **Context Management**: Add Context Curator Agent (#16) in Phase 5 to prevent token bloat
3. **Security/QA**: Make synchronous with timeout, not fully async
4. **PRD Quality**: Enforce rubric via Clarifying PM Agent (that's what we just built)
5. **Escape Hatch**: `/escalate` command from Phase 0, not Phase 9
6. **Phase 0 Priority**: Bootstrap skeleton → validate swappable agents → test model switching

### **Architectural Additions to Your Original Design**

| Addition | Purpose | Phase Introduced |
|----------|---------|------------------|
| **Context Curator Agent (#16)** | Compress conversation into "Design Ledger" to prevent context overflow | Phase 5 |
| **Regression Agent** | Validate Phase N's deliverables before starting Phase N+1 | Phase 7 |
